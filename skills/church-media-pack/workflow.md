# Church Media Pack Workflow

This document outlines the weekly rhythm for creative and media teams utilizing this skill.

---

## 🎨 Creative Production Timeline

```text
[Tuesday Morning]   ──> Preacher confirms sermon title, passage, and big idea
[Tuesday Afternoon] ──> Run the Church Media Pack Skill Prompt
[Wednesday Morning] ──> Generate images in Midjourney/DALL-E & design slide templates in Canva/Photoshop
[Thursday Morning]  ──> Schedule Instagram Carousel & social teasers
[Friday Morning]    ──> Import finished slides into ProPresenter/Proclaim; soundcheck with band
[Sunday Post-Service]─> Upload sermon video with generated YouTube title, description, and chapter markers
```

---

## 📋 Step-by-Step Procedure

### 1. Receive Sermon Theme
- Get the verified title, key passage, and main message from the teaching pastor.

### 2. Generate Prompt Pack
- Run the `church-media-pack` prompt with your desired aesthetic mood (e.g., earthy tones, warm film grain).

### 3. Generate Visual Assets
- Copy the Midjourney / DALL-E prompts into your image generation tool.
- Export backgrounds into Canva, Photoshop, or your design tool to overlay the series typography.

### 4. Build Slide Deck
- Place the generated slide copy directly into ProPresenter, Proclaim, or PowerPoint.

### 5. Schedule Social & Video Clips
- Format the 5-slide carousel for Instagram / Facebook.
- Shoot or edit 15-30 second video clips using the hook scripts.
